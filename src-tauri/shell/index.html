Starting the seeding server

The seeding server did not start

Nothing is listening on port 8765.

The usual cause is another copy already running — check the system tray and Task Manager for a second Seeding Ops (or a node app/server.js started from a terminal), close it, and start this one again.

If the server starts and then stops, the folder next to the application is missing app/, lib/ or config/, or .env has no STARTGG_TOKEN.
